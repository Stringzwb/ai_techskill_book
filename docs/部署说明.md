# 生产环境部署说明

运行环境要求 Java 17、Maven 3.6+、Node.js 20.19+、MySQL 8 和 Redis 6+。

## 固定流程

1. 在本地完成代码修改和数据库迁移脚本。
2. 本地执行后端测试与前端构建。
3. 按 Git 提交规范提交，并推送到远端 `main`。
4. 登录服务器后执行 `/home/ai_techskill_book/scripts/deploy-server.sh`。
5. 检查后端健康状态、首页、核心接口、Redis 和服务日志。
6. 在 `docs/deploy` 新增本次部署日志，并随下一次提交归档；重要部署应在本次发布前写好日志。

禁止直接修改 `/home/ai_techskill_book` 中的业务源码。服务器只允许通过 Git 快进拉取已经验证的提交。

## 环境变量

后端环境文件位于服务器 `/etc/ai-techskill-book/backend.env`，至少需要配置：

```text
DB_URL
DB_USERNAME
DB_PASSWORD
REDIS_HOST
REDIS_PORT
REDIS_PASSWORD
REDIS_DATABASE
SESSION_TTL
SESSION_SECURE_COOKIE
CORS_ALLOWED_ORIGINS
```

真实值只能保存在服务器环境文件或本地密钥管理工具中，不得提交到 Git。

## 回滚

部署脚本会把上一版产物保存到 `/opt/ai-techskill-book/backups/<部署时间>`。应用发布失败时，恢复其中的 `app.jar` 和 `frontend.tar.gz`，然后重启后端与 Nginx。数据库回滚必须根据对应迁移脚本单独评估，不允许直接删除生产数据。
