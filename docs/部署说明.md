# 生产环境部署说明

运行环境要求 Java 17、Maven 3.6+、Node.js 20.19+、MySQL 8 和 Redis 6+。

## 固定流程

1. 在本地完成代码修改和数据库迁移脚本。
2. 本地执行后端测试与前端构建。
3. 按 Git 提交规范提交，并推送到远端 `main`。
4. 登录服务器后执行 `/home/ai_techskill_book/scripts/deploy-server.sh`。
5. 检查后端健康状态、首页、核心接口、Redis 和服务日志。
6. 在 `docs/deploy` 新增本次部署日志，并随下一次提交归档；重要部署应在本次发布前写好日志。

禁止直接修改 `/home/ai_techskill_book` 中的业务源码。服务器只允许通过 Git 快进拉取已经验证的提交。

## 环境变量

后端环境文件位于服务器 `/etc/ai-techskill-book/backend.env`，至少需要配置：

```text
DB_URL
DB_USERNAME
DB_PASSWORD
REDIS_HOST
REDIS_PORT
REDIS_PASSWORD
REDIS_DATABASE
SESSION_TTL
SESSION_SECURE_COOKIE
CORS_ALLOWED_ORIGINS
STORAGE_ENABLED
STORAGE_ENDPOINT
STORAGE_ACCESS_KEY
STORAGE_SECRET_KEY
STORAGE_BUCKET
STORAGE_REGION
STORAGE_ENVIRONMENT
STORAGE_PATH_STYLE
AVATAR_MAX_SIZE
```

文档库使用同一套对象存储配置，Markdown 正文写入私有 `article` 目录。管理后台服务器必须配置相同的 `STORAGE_*` 值和 `STORAGE_ENVIRONMENT=prod`，但不得把对象键或存储凭据发送到浏览器。

真实值只能保存在服务器环境文件或本地密钥管理工具中，不得提交到 Git。

生产环境必须使用 `SESSION_SECURE_COOKIE=true`，并通过 HTTPS 提供登录功能。本地开发使用 HTTP 时才允许设置为 `false`。

生产环境启用头像上传时必须设置 `STORAGE_ENABLED=true` 和 `STORAGE_ENVIRONMENT=prod`。对象存储桶保持私有，真实凭据仅写入 `/etc/ai-techskill-book/backend.env`，更新时文件权限保持为仅 root 可写、服务用户可读。

## HTTPS 证书

当前公网 IP 证书由 Certbot 管理，证书文件位于 `/etc/letsencrypt/live/38.22.90.174`。IP 证书有效期较短，`certbot-renew-ai-techskill-book.timer` 每天检查三次续期，续期成功后自动重载 Nginx。每次部署必须确认定时器为 `active`，并使用 HTTPS 验证首页和接口。

## 回滚

部署脚本会把上一版产物和 Nginx 配置保存到 `/opt/ai-techskill-book/backups/<部署时间>`。应用发布失败时，恢复其中的 `app.jar`、`frontend.tar.gz` 和 Nginx 配置，然后重启后端与 Nginx。数据库回滚必须根据对应迁移脚本单独评估，不允许直接删除生产数据。
