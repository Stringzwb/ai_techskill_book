# 技术岗 AI 知识库安全接手说明

本项目不保存任何真实账号、密码、Token、私钥、对象存储密钥或完整环境文件。本文件只说明凭据位置和使用边界。

## 配置位置

| 用途 | 保存位置 | 仓库中的文件 |
|---|---|---|
| 应用运行时配置 | 服务器受限环境文件 | `deploy/backend.env.example` |
| SSH 连接参数 | 本机未跟踪的 SSH 工具配置 | `ssh快捷工具/config.env.example` |
| SSH 密码或私钥口令 | macOS 钥匙串或批准的密钥管理系统 | 无 |
| Git 访问 Token | macOS 钥匙串或服务器受限凭据文件 | 无 |
| Elasticsearch 和 Kafka 凭据 | 数据服务器受限环境文件或受限密钥目录 | `es/.env.example` |

## 连接服务器

在授权范围内可以正常连接服务器。使用本机 SSH 工具或已配置的 SSH 客户端；连接前确认目标、操作范围和预期结果。默认只做健康状态、版本、服务状态和迁移版本等只读检查。

不允许在聊天、AI 提示词、终端命令参数、普通日志或部署记录中提供或回显认证信息。需要验证环境配置时，只确认变量是否存在、权限是否正确，以及服务是否能建立连接。

## 提示词模板

```text
请在已授权的当前项目中完成 [目标]。
范围：仅 [本地代码仓库 / 指定服务器]。
允许操作：[只读检查 / 按既有发布流程部署 / 其他明确操作]。
禁止：读取或输出密码、Token、完整环境文件和原始会话日志；不要修改未关联文件。
验收： [测试、构建或健康检查标准]。
```

服务器变更、数据库迁移、服务重启、删除操作和生产数据修改必须单独明确授权。
